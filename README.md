# 💚 Poupa+

> Poupar hoje. Viver melhor amanhã.

Poupa+ é uma aplicação de gestão financeira pessoal criada para ajudar pessoas e famílias portuguesas a gerir melhor o seu dinheiro, criar hábitos de poupança e atingir os seus objetivos.

## Missão

Ajudar pessoas e famílias a viver com mais tranquilidade através de melhores decisões financeiras.

## Objetivos do MVP

- Login
- Dashboard
- Receitas
- Despesas
- Objetivos
- Coach Financeiro Lumi
- Índice de Saúde Financeira

## Tecnologias

Frontend
- Lovable

Backend
- Supabase

Base de Dados
- PostgreSQL

IA
- OpenAI
